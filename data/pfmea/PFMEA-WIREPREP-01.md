TITLE: Process Failure Mode and Effects Analysis - Wire Preparation
COMPANY: Anatolia E-Mobility Components
PROCESS: Wire Preparation
PRODUCT: HV Cable
STATUS: Released

# Process Step

Wire Preparation

# Potential Failure Mode

Broken copper strands were detected before terminal crimping.

# Potential Effect

Product performance may fail specification or create customer
assembly concerns.

# Potential Cause

Stripping blade penetration was too deep following blade replacement.

# Current Prevention Controls

Process setup verification, preventive maintenance and approved
work instructions.

# Current Detection Controls

Relevant checks include:

blade penetration, strand damage, blade replacement, conductor diameter

# Recommended Action

Add blade-position verification and first-piece microscopic inspection.
