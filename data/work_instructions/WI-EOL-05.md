TITLE: Work Instruction - Electrical Test
COMPANY: Anatolia E-Mobility Components
PROCESS: Electrical Test
PRODUCT: HV Cable Assembly
STATUS: Released

# Purpose

Define the approved method for the Electrical Test operation.

# Before Starting

Confirm correct product, tooling, program and inspection equipment.

# Process Checks

Operator must verify:

fixture contacts, micro-ohmmeter calibration, reference part, test leads

# Abnormal Condition

If the following symptom is identified:

Good assemblies intermittently failed resistance testing.

stop production and contact Quality.

# Known Risk

Historical investigation identified:

Worn measurement fixture contacts added unstable resistance.

# Required Prevention

Replace fixture contacts and establish fixture resistance verification.
