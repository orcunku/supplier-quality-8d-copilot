TITLE: Work Instruction - Crimping
COMPANY: Anatolia E-Mobility Components
PROCESS: Crimping
PRODUCT: HV Cable 95mm2
STATUS: Released

# Purpose

Define the approved method for the Crimping operation.

# Before Starting

Confirm correct product, tooling, program and inspection equipment.

# Process Checks

Operator must verify:

crimp height, applicator setup, pull force, operator setup approval

# Abnormal Condition

If the following symptom is identified:

Cable pull force decreased below the 2.8 kN requirement.

stop production and contact Quality.

# Known Risk

Historical investigation identified:

Incorrect crimp height setting was introduced after an applicator change.

# Required Prevention

Lock setup parameters and require first-off crimp height verification after tooling changes.
